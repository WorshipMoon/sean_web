# 购买的Facebook账号使用教程
## 手机端app登录(推荐)
第一步：输入账号与密码
打开 Facebook App，输入邮箱和密码后点击登录。

第二步：跳过设备通知验证
首次登录时，Facebook 通常会显示「在另一台设备上查看通知」页面， 要求在原有设备上批准登录。由于你是新接手的账号，不持有原始设备， 直接点击下方的「试试其他方式」。

第三步：选择身份验证应用
页面会展示可用的验证方式列表，选择「身份验证应用」， 然后点击「继续」。

💡 提示

「身份验证应用」选项对应的就是 2FA 密钥， 打开 2fa.run， 粘贴 2FA 密钥生成 6 位验证码后填入即可完成登录。

登录后注意事项
✅ 建议的养号操作

• 登录后先浏览信息流、观看视频，模拟真实用户行为
• 接收到 BM（商务管理平台）后，24 小时内不要进行任何操作，先挂机养号
• 至少正常使用 3 天后，再修改密码或其他敏感信息
• 始终保持 IP 稳定，不要在同一会话内切换节点
