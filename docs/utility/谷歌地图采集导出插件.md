# 谷歌地图采集导出插件

## 下载地址：

电脑上打开网址下载压缩包并解压

https://modsfire.com/2OU51Md2jf20PrJ



## 使用教程：
1. 浏览器输入网址的位置输入下方地址：

chrome://extensions/

2. 使“开发者模式”处于打开状态

![打开开发者模式](打开开发者模式.jpg)

3. 找到下面所示按钮点击加载下载的插件

Chrome

![加载未打包的扩展程序](加载未打包的扩展程序.jpg)


Edge

![加载未打包的扩展程序_edge](加载未打包的扩展程序_edge.jpg)


4. 在浏览器地址栏同一行找到扩展图标并点击

![扩展图标](扩展图标.jpg)

- 点击扩展名称（ Google Maps Scraper）

![ Google Maps Scraper](GoogleMapsScraper.jpg)
